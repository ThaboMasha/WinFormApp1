CyberSecureBot 🤖

Project Overview

CyberSecureBot is a Windows Forms chatbot application developed in C# to promote cybersecurity awareness. It allows users to interact with a chatbot, receive automated responses, and view previous conversations.

The application uses SQL Server LocalDB to store conversation records so that users can access their chat history even after restarting the application.

Features

* Interactive chatbot interface.
* Automated responses to user messages.
* Cybersecurity awareness information.
* User information capture.
* Conversation storage using SQL Server.
* Conversation history viewer.
* Search functionality for previous conversations.
* Refresh functionality to load the latest conversations.
* Persistent conversation records.

Technologies Used

* C#
* Windows Forms
* .NET
* Microsoft Visual Studio
* SQL Server LocalDB
* Microsoft.Data.SqlClient

Database Information

Database name: New CyberSecureBotDB

Table name: dbo.Table

The conversation table stores:

Column	Description
Id	Unique conversation record ID
UserMessage	Message sent by the user
BotResponse	Response generated by the chatbot
SentAt	Date and time of the conversation

Database Setup

1. Open SQL Server Management Studio (SSMS).
2. Connect to (localdb)\MSSQLLocalDB.
3. Open a new query window.
4. Run the following SQL script:

CREATE DATABASE [New CyberSecureBotDB];
GO
USE [New CyberSecureBotDB];
GO
CREATE TABLE dbo.[Table]
(
    Id INT IDENTITY(1,1) PRIMARY KEY,
    UserMessage NVARCHAR(MAX) NOT NULL,
    BotResponse NVARCHAR(MAX) NOT NULL,
    SentAt DATETIME NOT NULL
);
GO

Connection String

The application connects to the database using SQL Server LocalDB:

@"Data Source=(localdb)\MSSQLLocalDB;
Initial Catalog=New CyberSecureBotDB;
Integrated Security=True;
TrustServerCertificate=True;";

How to Run the Application

1. Install Microsoft Visual Studio with the .NET desktop development workload.
2. Ensure SQL Server LocalDB is installed.
3. Open the CyberSecureBot solution in Visual Studio.
4. Create the database and table using the SQL setup instructions above.
5. Build the project.
6. Run the application using F5.

Project Purpose

The purpose of CyberSecureBot is to demonstrate the development of a desktop chatbot application using C#, Windows Forms and SQL Server. It combines user interaction, automated responses and database management in one application.
